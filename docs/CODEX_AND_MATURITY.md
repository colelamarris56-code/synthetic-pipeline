# Community Clinic EHR Synthesizer — Codex + Maturity Model

## Purpose
Rules of the road for data, privacy, agents, governance, and growth stages.

## Clinical & Data Rules (capsule)
- FHIR-aligned extracts, UCUM units, ICD/SNOMED/LOINC mapping.
- PHI modes: safe_harbor | expert (date shift, ZIP3, rare-code suppression).
- Feature Manifests required for every extract (schema, ranges, pii tags).
- Agent envelopes: purpose-binding, record caps, audit.
- Governance: MD + RN + IT approve new extracts; equity strat required if group fields exist.

## Maturity Levels (1→6)
1) Compliance extracts  2) Clinical utility  3) Governance & equity  
4) QI loops  5) Scale/usability  6) Community health engine
